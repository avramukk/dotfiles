TODO file rules — keep it a pure task tracker, nothing else:
- Every line is either a heading (`## ...`) or a checkbox (`- [ ]` / `- [x]`).
- Facts, context, infra details, research notes → keep in the session context, NOT in the TODO file.
- No paragraphs, no tables, no long annotations under checkboxes.
- One line = one actionable item. Sub-steps only if a step genuinely needs splitting.
- Use `[x]` only for done+validated work.
- See prompts/TODO-template.md as the shape to follow.
